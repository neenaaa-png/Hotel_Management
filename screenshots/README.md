Screenshots Instructions

- `rooms.png` — Open [rooms.html](public/rooms.html) showing room list.

- `edit.png` — Open an Edit screen via the Rooms list (link to edit.html?id=...).
- `guests.png` — Open [guests.html](public/guests.html).
- `bookings.png` — Open [bookings.html](public/bookings.html).

Save images into this folder and name them exactly as above before submitting your lab.
